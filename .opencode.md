# Agent Rules for Worktree Environments

When creating a new worktree session using the `worktree_create` tool:

1. Wait for the `postCreate` lifecycle hook to finish executing.
2. Read the standard output logs of that hook. It will output a line matching: `INITIALIZATION_SUCCESS: http://localhost:<port>`.
3. In your very first response confirming the session is ready, you MUST explicitly extract that exact URL and present it cleanly to the user so they can click it to test changes.
